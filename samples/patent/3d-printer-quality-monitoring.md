# 3D 프린터 레이어 이미지 기반 출력 품질 모니터링

작성: 제조혁신팀 / 상태: 구현 착수

## 1. 목적

출력이 끝날 때까지 결함(레이어 어긋남, 언더익스트루전)을 모르고 지나가면
소재와 시간이 낭비된다. 레이어마다 즉시 이상을 감지해 출력을 중단시킨다.

## 2. 처리 흐름

각 레이어 완료 시점에 상단 카메라로 촬영한 이미지를 이전 레이어 대비
슬라이서가 생성한 기대 윤곽선과 비교한다. 실제 윤곽과 기대 윤곽의 IoU가
임계치 아래로 떨어지면 레이어 어긋남으로 판정한다. 표면 텍스처의 국소
분산이 급격히 커지는 영역은 언더익스트루전 후보로 표시하고, 두 프레임
연속 확인되면 출력을 일시정지하고 사용자에게 알린다.

## 3. 한계

투명 소재는 카메라 대비가 낮아 검출 정확도가 떨어져 별도 조명 보정이
필요하다.
