# 정수처리 응집제 자동 주입 제어 설계

작성: 환경플랜트팀 / 상태: 설계 검토

## 1. 목적

원수 탁도 변화에 따라 응집제 주입량을 자동으로 조절해 처리수 수질을
일정하게 유지하면서 약품 사용량을 최소화한다. 고정 주입량 방식은 탁도가
낮을 때 약품을 과다 사용한다.

## 2. 제어 로직

원수 탁도계 값과 유량계 값을 입력으로 받아, 사전에 확보한 자테스트(jar test)
데이터로 만든 탁도-최적주입량 회귀식을 기준값으로 삼는다. 처리수 탁도계
피드백이 목표치보다 높으면 기준값에 보정 계수를 곱해 주입량을 늘리는
피드백 보정을 5분 주기로 수행한다. 탁도 급변(강우로 인한 원수 악화)이
감지되면 보정 주기를 1분으로 단축한다.

## 3. 한계

수온이 낮아지는 겨울철 응집 반응 속도 저하는 이번 회귀식에 반영되지
않아 별도 계절 보정이 필요하다.
