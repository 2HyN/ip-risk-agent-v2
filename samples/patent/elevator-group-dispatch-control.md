# 초고층 빌딩 엘리베이터 그룹 배차 최적화 설계

작성: 빌딩시스템팀 / 상태: 시뮬레이션 검증

## 1. 목적

여러 대의 엘리베이터가 있는 건물에서 승객의 평균 대기 시간과 목적층 도착
시간을 함께 줄이는 배차 방식을 만든다.

## 2. 배차 알고리즘

승강장 호출이 발생하면 현재 각 엘리베이터의 위치·운행 방향·이미 배정된
승객 수를 반영해 예상 도착 시간을 계산하고, 그 값이 가장 작은 호기를 배정한다.
출퇴근 시간대에는 특정 층(로비) 집중 수요를 감안해 일부 호기를 로비 전용으로
고정하는 존 분할 모드로 전환한다. 배정된 뒤에도 다른 호출이 겹치면 재배정
비용(이미 이동한 거리)을 계산해 재배정 여부를 결정한다.

## 3. 검증

시뮬레이션에서 기존 최근접 배차 대비 평균 대기 시간이 개선됐다는 결과가
있으나, 실제 건물 적용 전 현장 데이터로 재검증이 필요하다.
