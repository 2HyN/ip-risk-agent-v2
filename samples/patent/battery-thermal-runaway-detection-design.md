# 리튬이온 배터리 팩 열폭주 조기 감지 장치 설계

작성: 배터리관리팀 / 상태: 시제품 검증

## 1. 목적

전기차용 배터리 팩에서 셀 하나의 열폭주가 인접 셀로 전파되기 전에 이를 감지하고
냉각 회로와 차단 회로를 구동한다. 기존 온도 임계 방식은 열이 표면까지 전달된 뒤에야
반응해 대응 시간이 부족하다.

## 2. 장치 구성

```
셀 모듈 (12 셀 직렬)
  ├─ 셀별 전압 센서
  ├─ 모듈당 온도 센서 4 개 (모서리 배치)
  ├─ 모듈 내부 압력 센서 1 개
  ├─ 가스 센서 (CO, VOC) 1 개
  └─ 감지 제어기
        ├─ 신호 조정 회로
        ├─ 판정 로직
        └─ 구동 출력 (냉각 밸브, 접촉기 차단)
```

압력 센서와 가스 센서는 모듈 상단 배기 경로에 둔다. 셀 안전 밸브가 열릴 때 방출되는
가스가 이 경로를 먼저 지나므로, 표면 온도보다 이른 시점에 신호가 잡힌다.

## 3. 신호 조정

각 센서 출력을 100 Hz 로 표본화한다. 온도와 압력은 차단 주파수 5 Hz 의 저역 통과
필터를 거치고, 가스 센서는 기준선 변동이 크므로 최근 10 분 이동 중앙값을 빼서
기준선을 제거한다.

## 4. 판정 로직

세 단계 판정을 둔다. 단계가 올라갈수록 대응 강도가 커진다.

### 4.1 1 단계 — 전압 강하율

셀 전압의 시간 미분을 구한다. 어느 셀이든

```
dV/dt < -50 mV/s
```

가 0.2 초 이상 지속되면 1 단계로 올린다. 내부 단락 초기에 나타나는 특징이다.

### 4.2 2 단계 — 압력 상승률과 온도 기울기의 결합

압력 상승률 `dP/dt` 가 2 kPa/s 를 넘고, 동시에 모듈 온도 센서 중 하나의 기울기
`dT/dt` 가 1.5 °C/s 를 넘으면 2 단계로 올린다.

두 조건을 곱 형태로 결합해 단일 지표를 만든다.

```
S = (dP/dt / 2.0) * (dT_max/dt / 1.5)
```

`S` 가 1 을 넘는 상태가 0.5 초 지속되면 2 단계다. 곱으로 결합하면 한 센서의
단독 이상으로는 지표가 오르지 않아 오작동에 강하다.

### 4.3 3 단계 — 가스 검출 동반

2 단계 상태에서 CO 농도가 기준선 대비 50 ppm 이상 상승하면 3 단계로 확정한다.
전해액 분해 가스가 실제로 방출된 상태이며, 열폭주가 시작된 것으로 본다.

## 5. 구동

| 단계 | 동작 |
|---|---|
| 1 | 해당 모듈 충방전 전류를 정격의 20 % 로 제한, 로그 기록 시작 |
| 2 | 냉각 밸브를 열어 해당 모듈에 냉매를 우선 공급, 상위 제어기에 경고 전송 |
| 3 | 주 접촉기 차단, 모듈 격리, 차량 경보 및 승객 하차 안내 |

3 단계 구동은 되돌리지 않는다. 판정이 사라져도 차단 상태를 유지하고, 정비 시
수동으로만 해제한다.

## 6. 센서 고장 처리

센서 신호가 측정 범위를 벗어나거나 200 ms 동안 갱신되지 않으면 해당 센서를 고장으로
표시한다. 고장 센서는 판정식에서 제외하되, 남은 센서만으로 2 단계 판정이 불가능한
경우에는 1 단계 제한을 상시 적용한다. 감지 불가를 정상으로 취급하지 않는다.

## 7. 검증 계획

- 못 관통 시험으로 인위적 내부 단락을 만들고 1 단계 검출 시점을 측정한다
- 과충전 시험에서 2 단계 검출과 표면 온도 임계 도달 시점의 시간차를 비교한다
- 목표는 기존 표면 온도 임계 방식 대비 8 초 이상 빠른 검출이다

## 8. 미해결

- 저온 환경에서 가스 센서 기준선 회복이 느려 3 단계 판정이 지연된다
- 모듈 간 열 전파 경로를 반영한 인접 모듈 선제 냉각 정책
