# 풍력 발전기 블레이드 피치 제어 알고리즘 설계

작성: 에너지시스템팀 / 상태: 필드 테스트

## 1. 목적

정격 풍속 이상에서 발전기 회전속도를 정격 범위로 유지해 과속 손상을 막고
발전량을 일정하게 유지한다.

## 2. 제어 루프

풍속계와 회전속도 센서 값을 받아 정격 회전속도와의 오차에 비례-적분(PI)
제어를 적용해 블레이드 피치각 목표값을 계산한다. 풍속이 급변할 때 피치
모터가 즉시 반응하면 기계적 스트레스가 커지므로, 목표 피치각 변화율을
초당 8도로 제한하는 슬루레이트 제한을 둔다. 돌풍으로 회전속도가 안전
상한을 넘으면 슬루레이트 제한을 무시하고 즉시 피치를 페더링 위치로 이동시키는
비상 로직이 별도로 동작한다.

## 3. 한계

저풍속 구간의 출력 최적화(MPPT)는 이 모듈 범위 밖이며 별도 모듈에서 다룬다.
