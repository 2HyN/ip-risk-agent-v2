# 실시간 통화 음성 기반 보이스피싱 탐지 모듈 설계

작성: 음성처리팀 / 상태: 구현 착수

## 1. 목적

통화가 진행되는 동안 수신 단말에서 발화를 분석해, 사기 통화로 의심되는 구간을
통화 종료 전에 식별한다. 서버로 원음을 전송하지 않고 단말에서 처리한다.

## 2. 전체 처리 흐름

```
마이크 입력
  → 프레임 분할 및 전처리
  → 음향 특징 추출
  → 화자 구간 분리
  → 발화 구간 임베딩
  → 사기 패턴 분류
  → 위험도 누적 및 경보 판정
```

## 3. 전처리

입력 신호를 16 kHz 로 재표본화하고 25 ms 창을 10 ms 간격으로 이동시켜 프레임을
만든다. 각 프레임에 해밍 창을 적용한 뒤, 잡음 구간에서 추정한 스펙트럼 하한을
빼는 스펙트럼 차감으로 배경 잡음을 억제한다. 잡음 추정치는 발화가 없는 것으로
판정된 최근 20 프레임의 이동 평균으로 갱신한다.

## 4. 특징 추출

프레임마다 40 차 멜 필터뱅크 로그 에너지를 구하고, 이산 코사인 변환으로 13 차
켑스트럼 계수를 얻는다. 여기에 1 차·2 차 시간 차분을 붙여 39 차 특징 벡터를
구성한다. 발화 단위 정규화를 위해 통화 시작 후 첫 3 초 구간의 평균과 표준편차로
각 차원을 정규화한다.

## 5. 화자 구간 분리

두 화자가 번갈아 발화한다는 가정 아래, 특징 벡터열에 대해 베이지안 정보 기준을
이용한 변화점 검출을 수행한다. 검출된 경계로 나눈 구간을 응집형 계층 군집으로
묶어 화자 라벨을 붙인다. 군집 간 거리는 구간별 공분산 행렬의 대칭 KL 발산으로
정의한다. 수신자 단말이므로 통화 초기 3 초의 근단 발화를 기준 화자로 고정하고,
나머지 군집을 원단 화자로 본다.

## 6. 발화 임베딩과 분류

원단 화자 구간만 모아 2 초 단위 세그먼트로 자르고, 각 세그먼트를 시간 지연 신경망
기반 인코더에 넣어 256 차원 임베딩을 얻는다. 인코더는 화자 식별 과제로 사전 학습한
뒤, 사기 통화·정상 통화 이진 라벨로 미세 조정한다.

분류기는 임베딩을 입력으로 하는 2 층 완전연결망이며, 출력은 해당 세그먼트가 사기
발화일 확률이다. 학습 시 정상 통화가 압도적으로 많으므로 클래스 가중치를 역빈도로
준다.

## 7. 위험도 누적과 경보

세그먼트 확률을 그대로 쓰지 않고, 지수 가중 이동 평균으로 누적 위험도를 만든다.

```
R_t = a * p_t + (1 - a) * R_(t-1),   a = 0.3
```

`R_t` 가 0.75 를 연속 3 세그먼트 동안 넘으면 경보를 낸다. 단일 세그먼트의 높은
확률만으로는 경보하지 않는다. 짧은 오탐이 즉시 경보로 이어지는 것을 막기 위한
조건이다.

경보가 발생하면 단말 화면에 경고를 표시하고, 통화 종료 시점에 위험도 시계열의
요약값만 서버에 올린다. 원음과 임베딩은 단말을 벗어나지 않는다.

## 8. 자원 제약

전체 파이프라인은 단말 CPU 단일 코어에서 실시간 계수 0.4 이하로 동작해야 한다.
인코더는 8 비트 정수 양자화한 가중치를 쓰고, 화자 분리의 계층 군집은 최근 60 초
구간으로 창을 제한해 계산량이 통화 길이에 비례해 늘지 않도록 한다.

## 9. 미해결

- 다자 통화에서 화자가 셋 이상일 때의 군집 수 추정
- 스피커폰 사용 시 음향 반향으로 인한 화자 경계 오검출

## 10. 발신번호 평판 조회

통화 수신 시점에 발신번호를 국가번호 포함 형식으로 정규화한 뒤, 단말에 내려받은
평판 목록과 대조한다. 평판 목록은 이용자 신고 이력과 통신사 차단 이력을 합쳐 만든
해시 집합이며 하루 한 번 증분만 내려받는다. 번호 전체를 서버로 보내지 않기 위해
해시 접두 8 비트만 질의하고 나머지 비교는 단말에서 수행한다.

대조 결과는 판정을 대신하지 않고 초기 위험도의 시작값으로만 쓴다. 평판이 나쁜
번호는 R_0 를 0.3 으로 두어 음성 기반 누적이 임계에 더 빨리 닿게 하고, 평판 정보가
없는 번호는 0 으로 둔다. 번호만으로 경보하지 않는 이유는 번호 변조와 발신번호
위조가 흔해 오탐과 미탐이 모두 크기 때문이다.
