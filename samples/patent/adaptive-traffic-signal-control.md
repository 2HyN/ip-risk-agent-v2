# 실시간 교통량 기반 신호 주기 적응 제어

작성: 교통시스템팀 / 상태: 파일럿 운영

## 1. 목적

고정 주기 신호는 시간대별 교통량 변화를 반영하지 못해 특정 방향에
불필요한 대기가 쌓인다. 교차로별 실시간 교통량으로 녹색 시간을 동적으로
배분한다.

## 2. 배분 로직

각 접근로의 루프 검지기 값으로 대기 차량 수를 추정하고, 교차로 전체
주기 길이는 고정한 채 접근로별 녹색 시간 비율을 대기 차량 수 비례로
재배분한다. 한 접근로가 과도하게 긴 녹색 시간을 가져가지 않도록 접근로당
최소·최대 녹색 시간 제약을 둔다. 인접 교차로 두 곳 이상에서 정체가 감지되면
녹색파(연동 신호) 모드로 전환해 주요 축의 통과를 우선한다.

## 3. 향후 과제

보행자 신호 요청과의 상호작용은 이번 설계 범위에서 제외했다.
