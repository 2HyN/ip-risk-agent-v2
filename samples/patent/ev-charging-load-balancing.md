# 공동주택 전기차 충전 부하 분산 제어 설계

작성: 에너지시스템팀 / 상태: 설계 검토

## 1. 목적

한 변압기에 연결된 다수의 충전기가 동시에 최대 출력을 요구하면 계약 전력을
초과한다. 차량별 목표 충전 완료 시각과 현재 배터리 상태를 받아 변압기 총
부하를 계약 전력 이내로 유지하면서 각 차량이 목표 시각까지 충전을 마치도록
전류를 배분한다.

## 2. 배분 알고리즘

각 충전 세션에 (남은 충전량, 목표 완료까지 남은 시간)으로부터 필요 최소
평균 전류를 계산한다. 전체 요구 전류 합이 배전 한도를 넘으면, 목표 시각까지
여유가 가장 큰 세션부터 순차적으로 전류를 낮추는 워터필링 방식을 5분 주기로
재실행한다. 여유가 없는 세션(목표 시각 임박)은 우선순위를 고정해 배분에서
제외한다.

## 3. 안전 로직

변압기 온도 센서 값이 임계치를 넘으면 배분 주기와 무관하게 즉시 전체 출력을
80%로 강제 하향한다.

## 4. 한계

전기요금 시간대별 차등은 이번 버전에 반영하지 않았다.
