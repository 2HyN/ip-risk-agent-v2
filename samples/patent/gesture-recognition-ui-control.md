# 깊이 카메라 기반 비접촉 제스처 제어 모듈

작성: HCI팀 / 상태: 구현 착수

## 1. 목적

수술실·클린룸처럼 손으로 화면을 만질 수 없는 환경에서 깊이 카메라만으로
화면을 조작한다.

## 2. 처리 흐름

깊이 카메라 프레임에서 손 영역을 배경과의 깊이 차로 분리한 뒤, 손끝 좌표를
컨벡스헐 꼭짓점 중 손바닥 중심에서 가장 먼 점으로 추정한다. 최근 8프레임의
손끝 궤적을 이동 평균으로 평활화하고, 궤적 방향 변화량으로 스와이프·핀치·
탭 세 가지 제스처를 분류한다. 오인식을 줄이기 위해 같은 제스처가 3프레임
연속 인식돼야 이벤트를 발생시킨다.

## 3. 한계

장갑을 낀 상태에서는 손끝 검출 정확도가 낮아진다는 필드 테스트 결과가 있어
추가 학습 데이터가 필요하다.
