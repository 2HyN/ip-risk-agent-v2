# 라이브니스 검증 포함 얼굴 인식 출입 통제 모듈

작성: 보안시스템팀 / 상태: 구현 착수

## 1. 목적

사진이나 영상 재생으로 얼굴 인식을 속이는 시도(스푸핑)를 걸러내면서
등록된 사용자를 빠르게 통과시킨다.

## 2. 처리 흐름

카메라 스트림에서 얼굴 영역을 검출한 뒤, 등록된 얼굴 임베딩과의 코사인
유사도로 신원을 판별한다. 라이브니스 검증은 짧은 시간(1초 내) 사용자에게
무작위 지시(눈 깜빡임 또는 고개 방향 전환)를 화면에 표시하고, 실제 반응이
지시와 일치하는지 프레임 간 변화로 확인한다. 신원 판별과 라이브니스
검증을 모두 통과해야 출입문이 열린다.

## 3. 한계

쌍둥이나 마스크 착용 상황에서의 오인식률은 별도 데이터셋으로 추가 검증이
필요하다.
